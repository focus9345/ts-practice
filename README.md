# TypeScript and Jest Practice

This repository contains practice exercises for working with TypeScript and Jest.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your machine. You can download them from [nodejs.org](https://nodejs.org/).

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/your-username/ts-practice.git
    cd ts-practice
    ```

2. Install the dependencies:
    ```sh
    npm install
    ```

### Running TypeScript

To compile the TypeScript code, run:
```sh
npx tsc
```

### Running Tests with Jest

To run the tests using Jest, execute:
```sh
npm test
```

## Project Structure

- `src/` - Contains the TypeScript source files.
- `tests/` - Contains the test files.

### Running the Application with lite-server

To serve the application using `lite-server`, run:
```sh
npm start
```
